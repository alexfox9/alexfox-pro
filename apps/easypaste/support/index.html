How to use EasyPaste

Start with one copy. Then learn how to keep, find, and use it again.

Examples use fictional text. This guide describes the current app source; release details and real screenshots are still pending.

Start here

Copy text, then use it again

For these steps, leave Auto paste off in Settings. It is off by default.

  1. In another app, select some text and press ⌘C.
  2. Open EasyPaste. The text appears in History.
  3. Click the item once. EasyPaste copies its full text.
  4. Return to your app. Click where you want the text, then press ⌘V.
Try this fictional text

Meeting notes: review the draft on Friday.

You can copy something else and still find this earlier text in History, until it is deleted or removed when the list fills up.

Choose History or Note

Two lists, two uses
ListUse it forExample
HistoryText captured when you copy.A link you copied a few minutes ago.
NoteText cards you choose to save and edit.A reply you send often.

History holds earlier copies. Note gives you a place to write and edit reusable text. Both lists have a 100-item limit. Read what happens when a list is full.

Choose Copy or direct Paste

Copy puts text on the clipboard. You choose a destination and press ⌘V. Paste also sends the paste command to the app you were using.

Use Auto paste

  1. Open Settings with the gear button or ⌘,.
  2. Turn on Auto paste.
  3. Click an item once to select it.
  4. Double-click the item to copy and paste it into your previous app.

Before returning to EasyPaste, click a text field in the app where you want to paste.

Use History’s More menu

Open More on a History item. Choose the action you need:

  • More → Copy copies, even when Auto paste is on.
  • More → Paste pastes directly, even when Auto paste is off.

Direct paste may need a macOS permission. If it does not work, follow the troubleshooting steps. You can still use Copy and ⌘V.

Keep important History items

  1. Find an item in History.
  2. Use its Pin button, or Pin in the item’s preview.
  3. The item moves into the Pinned group.

Pinned items stay when History fills up. Use Unpin to return an item to regular History.

Change the order

Clear Search, then drag pinned items into the order you want. Other History items are shown with the most recently used first.

If the row’s Pin button is hidden, open the preview. You can also turn on Show pin buttons in Settings.

Two different pins: an item’s Pin keeps its text in History. The toolbar pin keeps the whole window above other windows.

Save and edit text in Note

Create a card

  1. Open Note and click +.
  2. Enter your text. Add a Tag if you want a short label.
  3. Click Save, or press ⌘S.

Edit or reorder cards

Use the pencil on a card to edit its text. Save your changes. To change the card order, clear Search and drag the cards.

Save a History item as a Note card

  1. Find the copied text in History.
  2. Choose More → Add to Note. A Note editor opens.
  3. Review or edit the text and Tag.
  4. Click Save.
  5. Open Note to find the saved card.

Adding a card to a full Note list removes the card you created first. Moving that card does not protect it. See the storage limits.

Find text with Tags and Search

A Tag is a short label, such as “Reply” or “Project”. A Tag can have up to 20 characters.

  1. Add or edit a Tag in History’s More menu, a Note editor, or an item’s preview.
  2. In a preview, click the Tag icon or the Tag itself. Enter a label.
  3. Press Return to save, or Esc to cancel the preview Tag edit.

Search the list you are viewing

Enter a word from the text or a Tag in Search. Search checks the current list only. Switch between History and Note to search the other list.

Clear Search to show all items and to reorder pinned History items or Note cards.

Read the full text, or copy part of it

  1. Move the pointer over an item, or right-click it. A preview opens.
  2. Scroll inside the preview to read the full text.
  3. Select the words you need, then press ⌘C.
  4. Return to your app and press ⌘V.

Copying a selection lets you reuse part of a long item. Clicking an item with Auto paste off copies the full text.

Thanks for your message.

Make room beside your other apps

Collapse the window

  1. Open Settings and turn on Collapse View.
  2. Move away from EasyPaste. The window shrinks to a narrow strip.
  3. Move the pointer over the strip to expand it. You can also click its Search icon.

Keep the window above other windows

Use the toolbar pin. This changes the window’s position above other windows; it does not pin any text in History.

Change your preferences

Open Settings to change Theme, Transparency, Show numbering, Show pin buttons, Mute sound, and Ask before deleting.

Understand limits and deletion

Each list holds up to 100 items.

When History is full

Adding new text removes the unpinned item you have not used for the longest time. Pinned items are kept. If all 100 items are pinned, new text is not added. Unpin or delete an item to make room.

When Note is full

Adding a new card removes the card you created first. This happens even if you moved that card to another position.

Delete an item or a whole list

Use Trash on an item to delete it. In Settings, use Delete all Clipboard history… or Delete all Note items… to clear the chosen list.

Deleted items cannot be restored in EasyPaste. Keep any text you need elsewhere before deleting it. Pinning protects against History’s capacity limit, not against deletion.

Ask before deleting controls deletion prompts. It does not add an undo or restore feature.

When something does not work

Direct Paste does not insert text
  1. In your destination app, click a place where you can type.
  2. Return to EasyPaste. Try More → Paste in History, or double-click with Auto paste on.
  3. If macOS asks for permission, follow its prompt.
  4. To review permission, open Apple menu → System Settings → Privacy & Security → Accessibility. Turn on EasyPaste. If it is missing, use + to add the EasyPaste app you are running.
  5. Return to EasyPaste and try again.

Direct paste sends the normal paste command. The destination app still needs to accept text. If it does not, use More → Copy, return to the app, and press ⌘V.

Apple’s guide to app Accessibility permission. Copying text does not require this direct-paste permission.

I cannot find an item

Clear Search and check both History and Note. Search only checks the list you are viewing.

If the item was deleted or removed because its list was full, EasyPaste cannot restore it. Copy the original text again if you still have it.

New copied text does not appear

Check that EasyPaste is running. Copy some plain text, such as the fictional example above. History captures text; it is not an image history.

If History has 100 pinned items, unpin or delete one, then copy the text again. If a storage error appears, do not clear your lists to try to fix it. Include the exact error when contacting support.

I cannot reorder an item

Clear Search first. You can drag pinned History items within the Pinned group, or drag cards in Note. Regular History follows its most-recently-used order.
